# Small Talk Big Harvest — Voice Crop Advisor

Hack-Nation × World Bank "Small AI for Development" Hackathon (3–4 Oct 2026) · **Agriculture track**

A farmer gives a missed call from her basic phone, describes the problem on her crop **by voice in her own language**, and hears the likely cause and an expert-approved advice clip. Unsure cases go to a human extension officer. Every report feeds a village-level outbreak map.
